# EfficientPointMed

This project provides utilities for denoising and processing 3D CBCT medical images, extracting features, and generating point clouds for further analysis.

## How to Run

To execute the main 3D foreground extraction and denoising pipeline, use the following command:

```
python -m pipeline.3d_img_foreground
```

This will process the CBCT and mask data as configured in the script, apply denoising and feature extraction, and visualize the results.

---

For more details on usage or contributing, please refer to the code and docstrings in each module.
